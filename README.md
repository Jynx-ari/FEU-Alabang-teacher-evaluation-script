# FEU Alabang Teacher Evaluation Script

Automate your faculty evaluation process at FEU Alabang. Skip manual clicking and save time.

## ⚙️ Prerequisites

You must set up a userscript manager in your web browser before installing the script.

### 1. Install a Userscript Manager
Choose and install one extension for your browser:
* [Tampermonkey](https://tampermonkey.net) (Recommended)
* [Violentmonkey](https://github.io)

### 2. Enable Extension Permissions (Crucial Step)
Modern browsers require explicit permissions enabled for userscripts to run:
* Open your browser extension settings.
* Turn on **Developer Mode** (required for Google Chrome / Microsoft Edge).
* Click details on your userscript manager extension.
* Toggle the switch to **Allow access to file URLs**.
* Ensure **User Scripts** capability is enabled in the extension options.

---

## 🚀 Installation

1. Copy the full source code from the `script.js` file in this repository.
2. Open your userscript manager dashboard (e.g., Tampermonkey Dashboard).
3. Click the **Plus (+)** icon to create a new script.
4. Delete any default template text in the editor.
5. Paste the copied code into the editor.
6. Press `Ctrl + S` (or `Cmd + S` on Mac) to save.

---

## 📖 How to Use

1. Log in to your FEU Alabang student portal.
2. Navigate to the **Teacher Evaluation** section.
3. Open the evaluation form for a specific professor.
4. The script will automatically execute or provide an interface to complete the selections instantly.
